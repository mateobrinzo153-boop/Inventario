#Inventario

## Descripción

Programa desarrollado en Python para gestionar un inventario de 
productos. Permite agregar, consultar, buscar, eliminar y actualizar 
productos mediante un menú interactivo.

## Funciones

-Agregar productos al inventario.
-Ver todos los productos registrados.
-Buscar productos por nombre.
-Eliminar productos.
-Actualizar precio y cantidad de productos.
-Calcular el valor total del inventario.

## Estructura del proyecto

inventario/
├── main.py
├── inventario.py
└── README.md

-main.py: contiene el menú principal y controla el flujo del programa.
-inventario.py: contiene la lista de productos y las funciones para 
gestionar el inventario.
-README.md: contiene la información y documentación del proyecto.
